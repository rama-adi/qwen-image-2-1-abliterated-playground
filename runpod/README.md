# RunPod deployment

See the [main README](../README.md#runpod-deploy-the-published-image) for image publishing, RunPod settings, environment variables, and GPU verification.

This image uses the unquantized BF16 Heretic encoder and optional BF16 Heretic PE-T2I rewriter with the official BF16 Qwen Image 2.1 DiT and VAE. Mac's GGUF setup is separate. There are no quantized RunPod profiles.
